Make a project 
Step # 1: inside it make 4 more projects
- Business Objects 	-> Models or class objects which stores the data e.g Employee()
- Business Logic Layer	-> Manipulation of data being stored in Data base for example calculate salary for age<30 and age>30
- Presentation Layer	-> input from and output shown to the user
- Data Access Layer	-> to save or get data from Database e.g queries etc

Step # 2: include dependencies and write code make sure if there is a using in the file then you have imported the necessary dependency.
- N_tier_Architecture code:

- Business Logic Layer:
using Bussiness_objects;
namespace Bussinesslogic_layer
{
	public class BL
	{
		public Emp calculate(Emp obj)
		{
			if (obj.Age > 30)
			{
				obj.Salary = 500000;
			}
			else
			{
				obj.Salary = 300000;
			}

			return obj;
		}

	}
}
